PHANTOM X OFFICIAL DASHBOARD — STATIC WEBSITE UI

Files:
- index.html: website pages and layout
- style.css: responsive black/red theme and visual effects
- script.js: navigation, mobile menu, FAQ accordion and preview dialogs
- assets/: original PHANTOM X images from the supplied project

HOW TO USE:
1. Extract this ZIP.
2. Open index.html in a browser to preview the website.
3. For GitHub Pages, upload index.html, style.css, script.js and the complete assets folder to the repository root.
4. In GitHub repository Settings > Pages, select Deploy from a branch, choose main and /(root), then save.

IMPORTANT:
This is the UI-only build as requested. Google login, Supabase, GPlinks redirect verification, key generation, admin actions and database functions are NOT connected yet. Preview controls explain that these functions will be added later; they do not pretend to perform real backend operations.
